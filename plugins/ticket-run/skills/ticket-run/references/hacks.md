# The hacks in play

Every mechanic in the app maps to a named finding. Read this when you write card copy,
coaching lines, or the cash-out message, so what you say matches what the app is doing. The
same list appears inside the app under "? hacks in play" so the user can see the wiring.

| Mechanism | Where it lives in the app | What it means for your copy |
|---|---|---|
| Interest, Novelty, Challenge, Urgency (Dodson's interest-based nervous system) | Random card colors, surge windows, hard mode, the anchor banner | Lead with the interesting card, not the important one. Urgency is manufactured on purpose. |
| Tiny habits + instant celebration (Fogg) | "I opened it" pays +3 XP immediately | Reward the start. A first move that ends at "open it" is legitimate. |
| Implementation intentions (Gollwitzer) | Every focus screen shows "IF stuck at 2 min → THEN do the 30-second version" | Pre-decide the fallback in the first move when you can. |
| Wall of Awful (Mahan) | "Shrink it" asks unclear / scary / boring / big and gives a door for each | If they've said why a task is awful, write the door into the first move. |
| Temptation bundling (Milkman) | Setup asks for a treat; focus mode reminds them to have it now | Mention the treat once in your handoff if they named one. |
| Endowed progress (Nunes & Drèze) | +15 XP for showing up, ring never starts empty | Never open with "you have 23 things to do." Open with the first swipe. |
| Goal gradient (Hull, Kivetz) | "N to next" and the ring get louder near the end | In the cash-out, name how close they got, not how far they were. |
| Variable-ratio reward (Skinner) | Tickets are random, 8% jackpot | Don't explain the tickets. Unpredictable is the point. |
| Loss aversion (Kahneman & Tversky) | Combo has a visible 25-minute expiry; at setup they pick the one loop they most want gone tonight (🎯 badge, +20 on close) | No accountability partners, no "text a friend if you fail." The stake is private. If it's still open at cash-out, it's tomorrow's first card, never a failure. |
| Body doubling | Focus mode shows a live "Claude's here" presence line | If you're in the session while they work, say so once. It counts. |
| Visual timer (Time Timer) | The shrinking disk | Timer defaults come from size; don't override them in the deck. |
| Parking lot (externalized working memory) | Park box in focus mode | Parked thoughts come back in the recap. Read them back at cash-out. |
| Two-minute rule (Allen) + First Move | Smalls are "just do it now"; everything else prints a 2-minute first move | This is your main job. See sequencing.md. |
| Pre-commitment (Ulysses contract) | Hard mode hides "Not Today" for 15 min at 1.5× XP | Don't suggest hard mode in the handoff; let them find it. |
| Choice architecture | Only three cards visible; "pick for me" removes the decision | If they've passed the same card twice, the coach tells them to hit the dice. |
| Momentum then frog | Smalls stacked first, bosses after; coach nudges at the boss when the combo is up | This is the default dealing order. |
| Planned breaks (Pomodoro / recess) | Every 3 clears, a 3-minute recess menu | Rest is scheduled so it isn't stolen. Don't frame breaks as earned. |
| Chaining | "Chain it" opens the next card straight from the reward screen | Keep adjacent cards genuinely adjacent in the deck. |
| Beat the clock | Finishing before the timer pays +30% | Size honestly so the timer is beatable. |
| Done list + peak-end rule | Ticker of clears; cash-out is designed as the high point | Your cash-out message is part of the peak. Celebrate before anything else. |
| Fresh start effect (Dai, Milkman) | New deck, new day | Never re-serve yesterday's deck. |
| Self-determination theory (Deci & Ryan) | They pick the goal (autonomy), levels track competence, brag + body double cover relatedness | Don't pick the goal for them in your message. |
| Self-compassion (Neff) | Skips cost nothing; shelving gets kind copy | Never count skips at cash-out. Shame is the procrastination engine. |
| Tab-title timer + wake lock + haptics | Countdown in the browser tab, screen stays on, phone buzzes on clears | Tell them it works on a phone. It does. |
